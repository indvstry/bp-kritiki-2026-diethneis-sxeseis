# Proofing log

The proofreader's corrections, pasted **verbatim** — their wording, their
numbering, their language. One item per line. Do not reword, merge, or
classify anything here; this file is the record, not the analysis.

One `## Pass N` block per proofing round, newest at the bottom. Copy the
block below for each new round and fill in the round number, the date the
corrections arrived, and which proofing EPUB the proofreader read.

As each item is fixed, the fix commit appends a root-cause tag and the
commit hash to that line, e.g. `… έχει σπάσει η αράδα. → `line-break` 1f307ec`
(tags and procedure: "Proofing log" section of CLAUDE.md). Items left as ` → open` or
` → declined: reason` carry over to the next round. A line with no arrow is
not done yet.
